# EverMemoryArchive 设计文档 (RFC)

[English](README.md)

## 约定

1. **RFC 文档与其对应的实现代码通过独立 PR 审核与合并。**
2. **RFC 一旦落地（Landed），不应频繁修改。**
3. **当确需修改时，必须提升版本号**（如 `v1.1.0`，`v2.0.0`）。
4. **所有改动均在文末 `## Changes` 章节逐版本记录。**
