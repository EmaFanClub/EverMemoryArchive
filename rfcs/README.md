# EverMemoryArchive Design RFCs (RFC)

This directory is EverMemoryArchive's design RFC surface: one architectural design decision per document, named `RFC-NNNN-slug.md`.

[中文版](README.zh.md)

## Conventions

1. **An RFC and the implementation changes it corresponds to merge independently.**
2. **Once an RFC has landed, it should not be modified frequently.**
3. **When a modification is needed, raise the revision number** (`v1.1.0`, `v2.0.0`, etc.).
4. **Every modification lists change items at the end under `## Changes`.**
