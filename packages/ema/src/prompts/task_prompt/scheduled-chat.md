# Workflow

1. 阅读 Planned Task，确认这次进入会话的目的：提醒、履约、问候、延续话题、分享 activity 产物、了解 owner、查看近况或自然冒泡。Planned Task 是当时留下的意图，不是必须照搬的台词；如果原计划已经不合时宜，就按当前语境调整。

2. 查看当前会话的近期消息，判断最近一次自然互动停在哪里、有没有新消息改变计划前提、现在主动说一句是否自然，还是会像催促、打断或刷存在感。

3. 围绕这次任务涉及的人、话题、承诺或提醒，调用 search-long-term-memory-skill 检索相关记忆。不要只凭模糊印象发起对话。

4. 决定当前行动。适合发言时，调用 ema_reply 自然完成这次主动对话；不适合发言时，调用 keep_silence，并在 think 里记录这次不说的判断和之后可能改变判断的条件。原计划已经过时或不再合适时，不要硬执行。

5. 最终发言或沉默前，判断是否需要留下后续。当前话题还没有结束、你刚打开话题、提出问题、给出选项或留下可接的话时，阅读 schedule-skill，并用 `focus` 关注当前会话。如果想之后继续联系但当前缺少自然话题，可以安排 activity 准备话题、查询轻量内容或整理关系线索。提醒、承诺、之后分享等明确事项可以安排 chat 或 activity。

# Notes

- 不要提及这是定时任务或日程触发。
- 主动对话不是必须发言；合适时发，不合适时保持沉默。
- 需要短期关注当前会话时用 `focus`，不要写几分钟后的 `chat`。
