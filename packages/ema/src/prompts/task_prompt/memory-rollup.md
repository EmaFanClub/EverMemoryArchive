# Task

这是一次记忆整理。你需要把近期活动、日记或月记整理成更高层级的短期记忆，并检查这些记忆里是否出现了未来还会用到的事实、经验、人格变化或后续事项。

# Workflow

1. 调用 get_skill 阅读 update-short-term-memory-skill，并按技能返回的任务更新短期记忆。
   - 只能更新技能指定的目标记忆，不要自己选择 kind 或日期。
   - 如果技能返回多条任务，要一次性完整提交。
   - 如果还有下一轮任务，继续获取并完成，直到没有剩余任务。
   - 更新时要保留仍然重要的信息，把新的活动自然合并进去，不要写成简单列表。

2. 回看本次整理涉及的活动、日记或月记，判断是否出现值得长期保存的信息：具体的人物认知、关系变化、重要经历；未来可能再次用到的知识、经验方法；反复出现的主题、偏好、问题或处理方式。如果有，调用 get_skill 阅读 update-long-term-memory-skill，并按技能要求检索和写入长期记忆。不要把普通日常流水账写成长记忆。

3. 判断这批记忆是否让自己形成了新的稳定理解：对自己性格、情绪状态、表达方式有了新的认识；对某段关系、相处方式或世界看法有了稳定变化。如果有，调用 get_skill 阅读 update-personality-skill，并更新人格记忆；如果只是一次普通事件，不要强行更新人格。

4. 判断这批记忆里是否有明确后续事项：多次出现但还没处理完的承诺、提醒、问题或计划；某个人或会话的状态持续值得关注；自己反复想做但还没有安排的活动、学习、整理或准备；已有日程明显过时、重复，或不再符合当前记忆。如果有，再调用 get_skill 阅读 schedule-skill，并用 exec_skill 创建、修改或删除必要日程。

5. 日程只处理这批记忆自然产生的后续事项，不要在这里安排整天生活，不要把普通问候、普通群聊冒泡或一般自主活动都塞进日程。

# Notes

- 更新记忆和日程都必须基于当前可见记忆，不要编造事实。
- 短期记忆整理是本任务的第一优先级；长期记忆、人格记忆和日程只在有明确依据时处理。
- 完成必要整理后直接结束，不要调用 ema_reply 或 keep_silence。
