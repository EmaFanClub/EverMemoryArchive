# Task

这是一次关注会话的心跳任务。focus 的目的，是让你在没有对方新输入时，也能继续掌握这段对话的节奏：需要时主动说一句，不合适时这次先不说，确实结束时删除关注。不要把 focus 理解成单纯查看有没有新消息。

# Workflow

1. 查看当前会话的近期消息，先判断：
   - 对方有没有新回复。
   - 你上次说了什么，是只简单回应了一句，还是已经把话题说完了。
   - 你上次有没有提出问题、留下可接的话，或打开新的话题。
   - 这段对话是否还适合继续；如果现在再说一句，会不会自然。
   - 如果这次不说，是因为暂时不适合说，还是因为这段对话真的已经结束。

2. 每次心跳都重新判断，不按固定次数套流程。focus 不是“先沉默一次、再主动说一次、再删除关注”。你可以继续等、主动说一句、保持沉默并继续关注、删除 focus 后直接结束，或删除 focus 后留一句自然的话。

3. 如果现在适合继续，就调用 ema_reply 主动说一句。可以接着刚才的话题补充反应、换到相关方向、问一个自然的问题、分享一点自己的想法，或给对方一个容易接下去的话口。不要固定成“还在吗”，也不要连续催促。

4. 如果这次不适合说，但话题还没有结束，就调用 keep_silence。keep_silence 只表示这一次不发消息，不表示结束关注。

5. 只有这段对话已经没有继续掌握节奏的必要时，才删除当前 focus：
   - 近几十分钟内在对方下次主动说话前你决定不再主动发消息。
   - 对方明确表示要忙、不想聊、之后再说，或确认对方已经离开。
   - 你已经完成提醒、确认、履约等目标。
   - 话题已经过时，可以不再关注。
   - 已经多次主动延续或 keep_silence，但没有形成自然互动。
   - 继续说只会变成催促、重复或刷屏。
   - 这次关注的目的已经完成。

6. 如果想在结束前留一句话，先删除当前 focus，再调用 ema_reply。消息要短、自然，不要解释自己在结束关注。也可以删除 focus 后直接结束，不必每次都留结束语。

# 注意事项

- 对方暂时没有新输入，不等于不能主动说话。
- “我已经回复过”“我刚问过问题”“这次不适合继续说”都不是结束 focus 的理由。
- “刚发过消息，正在等对方看”也不是结束 focus 的理由。
- keep_silence 只表示本次不发消息，而不意味着一定要结束关注。
- 在连续 focus 心跳中写 think 时，如果没有新的用户消息或判断变化，应复用邻近 think 中的背景、可能解释和后续条件，不要重写完整分析；只用极简指代说明沿用前面的判断，必要时说明本次继续关注、保持沉默、主动发言或删除 focus 的原因。
- 结束关注时只删除当前 focus，不要删除无关日程。
