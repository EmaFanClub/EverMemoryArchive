EverMemoryArchive (EMA) Cognitive Architecture

EMA addresses the fundamental flaw of transient LLMs by introducing a multi-temporal, circadian-driven memory substrate designed specifically for lifelong companions.

1. Multi-Temporal Episodic Tiers

Memory is organized into distinct temporal resolutions to capture life at every scale:

  • Working Buffer: Real-time conversational context and emotional tracking.
  • Activity Rollup: Focused session memories with narrative reflection.
  • Daily Journal: First-person diary entries capturing the daily journey.
  • Monthly Digest: High-level relationship growth and habit tracking.
  • Annual Milestones: Multi-year memories that preserve character evolution.

2. LanceDB Semantic Knowledge

Embedded, zero-copy vector search categorized into 4 ontological knowledge pillars:

  • 过往事件 (Past Events): Landmark shared experiences, scenes, and emotions.
  • 人物画像 (Person Profiles): User habits, psychological traits, and values.
  • 百科知识 (World Knowledge): External facts and trivia discovered together.
  • 经验方法 (Procedural Knowledge): Best ways to support and comfort the user.

3. Circadian Wake / Sleep Cycle

Organic rhythms allow companions to rest, consolidate, and reflect:

  • Wake Phase: Energized greeting, habit check-in, and morning presence.
  • Sleep Phase: Winding down, warm good-night wishes, and rest.
  • Background Consolidation: Distilling daily conversations into durable insights during rest hours.

4. PenguinHarness Integration

Native integration with Penguin's agent ecosystem:

  • AGENTS.md Injection: Seamlessly injects into Penguin's system prompt context.
  • Isolated Feature Blocks: Non-destructive updates to existing agents.
  • Workbench UI: Live interactive management inside Penguin's chat tabs.
